# RRFC — Rec Room Football Community

Simple static website (gold & black) inspired by league profile sites.

## Preview locally

Open `index.html` in your browser, or from this folder run:

```bash
npx --yes serve .
```

Then visit the URL it prints (usually http://localhost:3000).

## Pages

- Home, Players, sample Player profile
- Standings / Schedule / Teams / Stats / Staff / Accolades / History (placeholders)
